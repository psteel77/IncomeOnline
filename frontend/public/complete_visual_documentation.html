6. Authentication System

Magic Link Flow

Income Online uses a secure, password-less authentication system called "Magic Link":

For New Users:

  1. User makes a donation via PayPal
  2. Email is added to authorized users database
  3. User clicks "Returning User" on AccessGate
  4. Enters email address
  5. Receives verification email with magic link
  6. Clicks link to authenticate
  7. Full access granted automatically

For Returning Users:

  1. Click "Returning User" on homepage
  2. Enter registered email address
  3. Receive new magic link via email
  4. Click link to authenticate
  5. Instant access to all content

🔐 Security Features

  • One-Time Use Tokens: Each magic link can only be used once
  • JWT Authentication: Secure JSON Web Tokens for session management
  • 30-Day Expiration: Tokens expire after 30 days
  • No Passwords: Password-less system eliminates password vulnerabilities

API Endpoints

Authentication Endpoints

  • POST /api/auth/request-access - Request magic link
  • GET /api/auth/verify/{token} - Verify magic link token
  • GET /api/auth/check - Check authentication status
  • POST /api/auth/add-donor - Add authorized user

Content Endpoints

  • GET /api/categories - Get all categories
  • GET /api/platforms - Get platforms (with filters)
  • GET /api/platforms/{id} - Get single platform
  • GET /api/stats - Get statistics
  • GET /api/content - Get CMS content

CMS Endpoints

  • POST /api/cms/login - Admin login
  • GET /api/cms/content - Get all content sections
  • PUT /api/cms/content/{section_id} - Update content section
